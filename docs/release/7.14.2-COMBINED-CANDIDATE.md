## Full-diff audit, 2026-09-12

This candidate was audited by reviewing every changed file against its base,
not by re-reading the summaries above. 249 findings were raised across the
three release lines; the 104 rated P1/P2 were each re-checked by three
independent reviewers along separate lines of attack (is it reachable, does it
matter on a shipped release, is it already covered), and 84 survived that.
Everything that survived and applies to this line is fixed at the head below.

Each fix carries a test, and where a control was possible the unfixed code was
built and the test confirmed to fail against it -- a test that passes either
way is recorded as such in the file rather than counted as coverage.

Findings on this line are listed with their resolution in `audit-units/`.
The load-bearing ones for a reader of this receipt:

- cipher recovery committed the EMPTY mnemonic when a ceremony was driven with separators only
- the address confirmation screen showed the first 44 characters of a 62-character bech32m address beside a QR encoding all of it: the second row was drawn off-canvas and dropped silently, and the fix for it had been added to this line and then reverted
- the THORChain deposit decoder was not pinned to a router, so deposit-shaped calldata to any contract inherited the clear-sign UX and skipped the AdvancedMode gate
- the XRP ceiling was 1e6 too low; CACAO deposits rendered at zero decimals
- the commit CRC left the last byte of the V17 record outside write verification while a unit test asserted the opposite
- layout_debuglink_watermark() was deleted while the bootloader still called it, so no DEBUG_LINK device image could be built
- auto-lock measured wall-clock rather than idleness and tore down live ceremonies

Two defects were found in the audit's own work and corrected the same way: a
router pin that refused Maya deposits (CI caught it), and a `const` violation
that only ARM GCC rejects (the emulator's clang accepts it). Local ARM
cross-builds using CI's own base image now cover every variant.
