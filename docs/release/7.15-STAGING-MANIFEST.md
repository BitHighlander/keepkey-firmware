## Validation evidence

The assembled native firmware, board and crypto suites pass after the storage
signed-byte fix and dependency updates. Nine real UDP EVM/Solana provider tests
pass. Ten production-handler tests cover consent ordering, cancellation, policy,
authentication, malformed icons, slot overflow and midstream injection. Twenty
legacy metadata tests pass with the new consent fixture. The complete native
host suite passes: 444 passed, 36 skipped, and two EOS vector subtests passed.

Two EVM integration cases failed before the metadata lifetime/final-digest fixes
and passed afterward. Storage unsigned-field/absent-secret regression failed
before unsigned-byte decoding and passes afterward. A freshly wiped emulator
image now survives restart as uninitialized; an imported public test wallet also
survived restart. The older corrupt image remains evidence, not a supported
format migration. See the foundation review for the precise failure mechanism.

Native validation uses AppleClang, PB_NO_PACKED_STRUCTS and a local Ninja command
correction to select pinned nanopb 0.3.9.4. These are disclosed host accommodations;
production Linux/ARM CI is authoritative for those configurations.
