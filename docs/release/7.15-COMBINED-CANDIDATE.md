## Full-diff audit, 2026-09-12

This candidate was audited by reviewing every changed file against its base,
not by re-reading the summaries above. 249 findings were raised across the
three release lines; the 104 rated P1/P2 were each re-checked by three
independent reviewers along separate lines of attack (is it reachable, does it
matter on a shipped release, is it already covered), and 84 survived that.
Everything that survived and applies to this line is fixed at the head below.

Each fix carries a test, and where a control was possible the unfixed code was
built and the test confirmed to fail against it -- a test that passes either
way is recorded as such in the file rather than counted as coverage.

Findings on this line are listed with their resolution in `audit-units/`.
The load-bearing ones for a reader of this receipt:

- cipher recovery committed the EMPTY mnemonic when a ceremony was driven with separators only: the count gate passed with zero words and the wire-default enforce_wordlist skipped the checksum, so the device stored a publicly derivable seed and reported success
- BIP-85 child seeds were drawn with the unpaged constant-power renderer, which drops every character after the first that will not fit -- pages are packed at 225 px and drawn at 124 px, and the widest page this packer emits does not fit (measured)
- the MAYAChain send screen scaled every host-chosen denom by CACAO's 1e10, so 1 'maya' displayed as the value of 1,000,000
- consent screens bypassed the measured renderer, the >99-page cap truncated instead of refusing, and a body vsnprintf() had already cut could still be approved -- all three reverted into this candidate by a56fb3e88 while keeping the comments that describe the opposite
- the THORChain memo's ABI tail padding was signed unchecked (up to 31 attacker-chosen bytes) and the deposit decoder was not pinned to a router, so deposit-shaped calldata to any contract inherited the clear-sign UX and skipped the AdvancedMode gate
- Tendermint envelopes (both chains) armed before validation, accepted messages past their declared budget, and MAYAChain never emitted the msgs[] comma separator -- a two-message document hashed as invalid JSON
- multisig quorum was validated on outputs but not inputs, where m feeds the weight and the excessive-fee threshold
- Hive signed the display asset symbol ('HIVE') where hived writes 'STEEM'; the device's own golden vectors, captured from hived, said so, while the integration test asserted the firmware's mistake
- auto-lock measured wall-clock rather than idleness and tore down live ceremonies; the lock's own abort redrew the home screen, so the screensaver vanished one tick after locking
- two release gates exited 0 having read nothing, reporting '0 files checked' as a pass
- the Hive account-name nanopb bounds were a byte short of the protocol's 16 characters (max_size counts the NUL), so a legal account was refused inside pb_decode, before any handler could say why

Two defects were found in the audit's own work and corrected the same way: a
router pin that refused Maya deposits (CI caught it), and a `const` violation
that only ARM GCC rejects (the emulator's clang accepts it). Local ARM
cross-builds using CI's own base image now cover every variant.
