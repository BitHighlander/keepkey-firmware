# Foundation reconstruction: bounded review dispositions

PR #635, initial head 49b93af5428dff2d849418cba308a41e4bb84d95.
Copilot round 1: review 5138331902, Lite, 162/344 files reviewed. Its findings
are evidence about the reconstruction, not a complete firmware audit.

## Confirmed and remediated

- 3955120102: tiny-json exported libc's errno name. Restore library-specific
  json_errno, avoiding platform macro/TLS collisions.
- 3955120248: duplicate stack-canary definition with inconsistent host width.
  Keep the single uintptr_t definition in board code.
- 3955120329: EOS waits hashing used accounts_count. Use waits_count; independent
  count regressions fail with the previous loop and pass after correction.
- 3955120351: EOS standard authority confirmation omitted account delegations.
  Reject that shortcut when accounts_count is nonzero; regression fails before.
- 3955120439: mixed short raw key plus derivation path could select different
  keys for display and hashing. Require exactly one complete key source in both
  hashing and confirmation; test all raw lengths 1–33 with a derivation path.
- 3955120380: emulator CRC processed bytes with reflected CRC rather than STM32
  words. Restore alpha's word-oriented peripheral model and known-answer/tail
  corruption regressions. Device CRC is unchanged.
- Review-body CI claim: firmware-unit.sh returned cp status instead of make.
  Restore alpha's explicit test-result exit; retain report extraction on failure.

## Explicit scope dispositions

- 3955120169, 3955120224, 3955120298: Windows emulator support is intentionally
  absent from this 7.14.2 foundation, including its MinGW toolchain. The selected
  emulator matrix is Linux/macOS; /dev/urandom is the POSIX system CSPRNG and
  failure terminates instead of returning weak bytes. A Windows unit must carry
  all platform sources/toolchain/tests together; partial includes are not a fix.
- 3955120193: delay_ms requires timer initialization. The supported emulator
  uses SIGALRM/ualarm in timer_init to decrement remaining_delay. This is an
  existing initialization contract, also exercised by native and Linux tests;
  no supported-platform hang reproduction was supplied. Windows is omitted as
  above. Reopen for a concrete initialized Linux/macOS reproduction.
- 3955120139: the additional statistical RNG health layer is absent from the
  selected foundation; random_buffer still uses random32's STM32 error-status
  checks and repeated-word rejection. That is not equivalent to alpha's fuller
  health gate. Preserve this as the OTP/RNG prerequisite for the dedicated RNG
  extraction, before any release acceptance; do not silently import dice and
  the RNG subsystem through a foundation-review fix.
- 3955120414: alpha's fault-injection hardening is intentionally outside this
  base reconstruction. The existing verifier still requires three distinct,
  unexpired signing keys and three successful ECDSA verifications. The residual
  firmware_fingerprint is a hash of public firmware, not secret key material.
  No concrete bypass was supplied. Additional physical fault resistance needs
  its own scoped unit and validation; this PR makes no bootloader-hardening or
  physical fault-resistance claim.

These dispositions do not authorize release or erase the recorded limitations.
Internal feature staging can continue under the owner's unmerged-stack policy.
