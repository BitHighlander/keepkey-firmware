Groups structure fields without hiding them. An iteration walks exactly one
array, reached through tuples, in a calldata definition. Every field inside
must read that active array, so a scalar cannot be repeated for each element.
Only the `optional` condition runs, and it always shows the field. All
visibility rules that could hide a field are refused at preload. The host
mirror makes the same decisions.
