Findings and evidence

  • P02-001, P02-002 and P02-003 receipts record failure-before reproductions and focused passing native results. The exact candidate CI run 34951131013 passed at 7e091af157131897adc5514de392570c32088946: full and Bitcoin-only ARM builds, unit suites and host integration, emulator builds, Python dylib, crypto, static analysis, formatting, submodule/secret checks, report generation and CI gate.
  • 7e091af15..614425a2a changes only CI workflow files. Firmware source, tests and dependency pointers are identical. The earlier run supports Block 2 behavior; it does not certify the later workflow refactor.
  • F161: the packet-storage UDP regression is compiled only in the full variant. Bitcoin-only runs the tiny-message test and its complete native suite. Device USB callback paths were source reviewed and ARM built, but not exercised by that native regression.
  • F204: a shared UDP port may cause test interference. The packet test consumes one datagram and restores the FSM callback before assertions; the exact candidate CI completed. Flakiness is a test risk to watch, not proven absent by one pass.
  • F205: the local poll result is assigned from each synchronous call before its loop condition is read; no asynchronous writer modifies that local, so a volatile qualifier would not strengthen this check.
Remaining boundaries: physical USB/OLED and signed-upgrade checks are release gates, and the CI workflow refactor needs its own exact-head gate. This report does not claim hardware execution, product promotion or zero possible defects.
