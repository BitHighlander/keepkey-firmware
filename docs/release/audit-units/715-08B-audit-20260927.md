## Static-analysis execution and failure behavior

The shared script preserves CI's analysis flags, includes, defines, output template, source directories and nonzero-on-finding policy. It requires one literal output pathname. Parallelism is obtained inside the execution environment with getconf, not parsed from YAML. The local container mounts source read-only and gives only the analysis cache a writable temporary mount; diagnostics go to the container's temporary directory. Container or analyzer failure is propagated directly. A missing package/image, stale package, wrong executable, missing Docker or failed test prevents preflight success.

Package version is pinned and checked, not inferred from a cached image tag. Distribution image updates can still alter unrelated OS dependencies; the claim is identical analyzer package/version and argv, not byte-identical operating systems across host architectures. The CI runner and local container may have different CPU architectures. Exact-head CI remains required acceptance evidence in addition to local preflight.
