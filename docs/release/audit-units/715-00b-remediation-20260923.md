### Additional findings exposed by executing the missing suites

1. **Native value consent:** v2 metadata matching computed `metadata_schema_moves_value`, but Ethereum discarded it and suppressed the amount screen. The caller now preserves that confirmation; matching/reset clear stale state. `SignedMetadataTest.PayableSchemaCannotSkipNativeAmountConsent` fails when the caller is restored to its old behavior. `V2SchemaPreservesNativeValueConfirmation` checks nonzero, failed rematch and zero transitions.
2. **Dormant crypto build drift:** Zcash tests used the old four-argument RedPallas signing API and omitted the pinned `pallas_ct.c` implementation. Tests now provide an explicit 80-byte randomness fixture and link the required implementation. No production signing randomness is replaced.
3. **Dormant fixture drift:** runtime-signer tests omitted the existing AdvancedMode precondition; their fixture now establishes it, while a separate negative test proves off-mode rejection. Two old expectations conflicted with current supported behavior: payable schemas retain native-value review, and fixed-word BYTES is supported. `FixedBytesSchemaDecodesEntireWord` checks all 32 decoded bytes and rejects the second display page. Unsupported dynamic STRING remains rejected.
4. **Build portability:** move shared-library links to the target’s defining CMake directory so the declared minimum CMake does not need the newer cross-directory-link policy. GCC diagnostic builds exercise C11 atomics; the older container Clang lacks `stdatomic.h` for the shared library. Ordinary Clang full/BTC and GCC shared-library builds are recorded separately.
