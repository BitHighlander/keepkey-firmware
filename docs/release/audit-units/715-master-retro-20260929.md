## 6. What worked

- **Independent read-only audits before paid review.** They found real defects that Copilot had not: the Block 11f PIN-cancel path that left an identity fingerprint on the stack, Block 12's unwired Pallas checker, a duplicate-identity hole in the report gate, and Block 13's merge interaction risk (which came back clean, with a control to prove it).
- **A failing control for every claim.** Ten mutation or reverting controls were run this week (OTP recovery, lock clearing, wipe observability, Hive serializer roles, the report gate, the Pallas checker, the merged storage guard, the Osmosis cap). Each one either proved a test detects the defect or exposed a vacuous test, notably the OTP probe that modelled a write as a copy.
- **Artifact verification against the exact head**, not "CI is green": head, run and pin identity, PDF and JUnit hashes, per-variant native identities and ARM manifests.
- **The severity rule (2026-09-29).** Nit-only rounds pass; only serious or moderate findings count. It was written to stop the pattern that produced nine reviews on Block 00b and four on Stack 01; it has been applied to Blocks 11 to 13 and has not yet been tested on a full block.
- **Bundles as durable handoffs.** Block 13's isolated clone was gone, and its work came back intact from a verified Git bundle.

## 7. What did not work, and the cause

| Problem | Cause | Evidence | Change |
| --- | --- | --- | --- |
| Assembly gap (section 4) | Blocks audited against provisional predecessors; assembly deferred | Presence table, forecast | Perform assembly as its own audited unit before any merge |
| Review loops on nits | Copilot findings treated as pass/fail regardless of consequence | 00b: nine reviews; 122 reviews and 314 threads overall | Severity rule in the SOP |
| Tests that pass without proving anything | Fakes that model the wrong physics or observe the wrong thing | OTP probe (write as copy), node-only wipe checks, identical entropy draws, a reader that took `##` inside a payload for a header | A failing control before a test is trusted |
| Gates that do not gate | Wiring never checked | Unreferenced Pallas checker; duplicate identity accepted by a set; earlier "silent skip" and symbol-blind gate classes | Every gate needs a control that makes CI red |
| Stale evidence churn | Reports naming their own head; PR counts and run IDs edited by hand | Repeated report refresh cycles in every block | A report states the code head it verified; the PR records the final head |
| Environment | Local Docker unresponsive all week; zsh does not split unquoted variables; runner flakes | Hosted-only native suites; several silent wrong counts before I caught them | Preflight and verification in scripts, bash only, reruns of failed jobs only |
| Shared main worktree | The SOP is untracked in the main worktree and was edited there by several agents | The severity edit exists only locally | Commit the SOP and ledger to a tracked branch |

## 8. Decisions taken (with where they are recorded)

- Block 11 split into ten bounded units after its fourth review (owner-authorized recursive splits).
- Osmosis send cap lifted for non-native denominations; auto-lock renewal left unchanged and tracked as issue #891; the recovery re-roll is not a defect (Block 13 report).
